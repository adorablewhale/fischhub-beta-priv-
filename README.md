### how to join

run regular [fischhub](https://github.com/adorablewhale/fischhub) once to accept the agreement and register your client. send me your roblox user id so i can approve it, then paste the beta loader in matcha while in fisch. a new client needs approval again.

### what it adds

- bellona's two reels, controlled independently.
- perfect casting, minimum control width and water reach diagnostics.
- searchable rods, fish esp, aurora stand buying, npc appraisal and measured reel speed.
- separate beta settings and keybind overlay position saving.

this is a beta. some rods and lifecycle cases still need checks. instant catch and custom-width changes currently affect the primary reel only. buying and appraisal spend your in-game money when enabled.

the gameplay build is delivered by the website after access checks. this repository holds the loader only. removing access blocks future beta loads; already-loaded code is not remotely erased.

### data and agreement

the same insui agreement covers your beta sessions: roblox name and user id, script/version/game, launches, session status, counters and menu settings are sent to your private dashboard and the owner's admin page, kept 30 days. passwords, chat and debug logs are not sent. beta permissions stay until the owner removes them. discord setup stays on the website.

beta auto-execute starts off. if you enable it in the gear menu, disable regular fischhub auto-execute so only one runs. manual loading replaces the regular script without changing its settings.
